DESCRIPCIÓN DE LA ACTUALIZACIÓN:
Se conservó el contenido original (carrusel, equipo y pilares de valor) 
y se agregó una nueva sección de "Servicios Exclusivos" utilizando CSS Grid.
Se migró toda la iconografía a FontAwesome (para mantener la coherencia
visual requerida en la rúbrica) y se aplicaron Media Queries para 
garantizar que la página se adapte a móviles y tablets sin desbordes.

CUMPLIMIENTO DE LA RÚBRICA:
- Flexbox y CSS Grid: Organizan el layout, los pilares y los nuevos servicios.
- Media Queries: El diseño fluye en 992px y 576px.
- Uniformidad: Uso de variables :root, fuente Inter e iconografía azul unificada.
- Estructura: Etiquetas header, nav, main, section, aside y footer.
